Privacy Policy

Last updated: November 23, 2026.

Purpose and access

Instagram Drive Bot is a personal tool that retrieves publicly accessible videos from supported platforms and stores them in the owner's Google Drive. The bot's Google authorization is for the owner's Google account, not third-party accounts. The Google Drive drive.file permission limits the bot to files it creates or selects through its authorization.

Information processed

The service processes video links from supported platforms sent to the Telegram bot and the sending user's Telegram identifiers and chat ID in order to authorize requests and send replies. The authorized request is encrypted before being passed to GitHub Actions. Google's OAuth credentials are stored as private GitHub Actions secrets. We do not ask Telegram users for Google passwords.

Where data goes

Cloudflare receives the Telegram webhook, GitHub Actions downloads the requested media and uploads it using Google Drive API, and Telegram sends the result. These infrastructure providers may process operational metadata according to their own policies. The service does not operate a separate application database for chat messages. Request-processing metadata may still appear in service logs or provider systems.

File sharing and retention

Video files and the Instagram Videos folder are configured for viewing by anyone with their links. Do not submit sensitive or private videos. Saved videos remain in the owner's Google Drive until the owner removes them; provider log retention is governed by each provider's settings. The owner can revoke Google authorization via their Google Account security settings.

Contact

For questions about this open-source project, use GitHub Issues. Do not post private credentials, chat IDs, or personal information in public issues.
