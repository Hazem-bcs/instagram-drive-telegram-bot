What this application does

Instagram Drive Bot is an owner-operated Telegram bot that saves publicly accessible videos from Instagram, YouTube, Facebook, TikTok, X, Reddit, Vimeo, Twitch, Dailymotion and Streamable to the owner's Google Drive account and replies with a video link in Telegram.

This is a personal utility, not a service for connecting other users' Google accounts. Only an authorized Telegram user can send download requests. It uses Google Drive API's drive.file authorization to create and manage its own files and folders.

Video transfers are processed through Cloudflare Workers and GitHub Actions. The saved Drive folder and video files are shared as anyone with the link can view. Only submit public content that you are allowed to download and share.

Using the bot

The service is accessible to the owner's approved Telegram account. There is no separate account registration or subscription.
